# Курсова: інтеграція C++/ROS 2 з AirSim

Навчальний стенд запускає готову сцену AirSim, читає телеметрію в реальному
часі й показує стан симуляції у локальній панелі. Можна вибрати один із десяти
наборів вхідних даних, відтворити власний `simulation.json` із ДЗ10 або
порівняти записаний шлях AirSim із CSV-журналом телеметрії ДЗ11. Апаратне обладнання не
використовується.

## Що входить у репозиторій

- `src/` — C++ вузли ROS 2 та адаптер AirSim;
- `launch/` — окремі запуски ROS-демо та AirSim;
- `scenarios/` — десять наборів `config.json`, `targets.json`, `ammo.json`
  і спільна балістична таблиця;
- `windows/` — локальна панель, скрипти запуску й невеликі текстури для
  відображення об'єктів;
- `docs/` — встановлення, архітектура та журнал перевірок.

Цей каталог розміщується всередині репозиторію `Cpp_white_miltech`: збірка
використовує вихідні файли сусідніх `homework_10` та `homework_11`. Вихідний
код і готова Windows-сцена AirSim **не включені** до цього каталогу.

## Швидкий старт

1. Підготувати Windows, WSL/контейнер із ROS 2 Jazzy, C++ залежності AirSim
   і готову сцену — точний список у [docs/SETUP_WINDOWS.md](docs/SETUP_WINDOWS.md).
2. Зібрати пакет у контейнері командою з інструкції. Збірка для демонстрації
   повинна містити `airsim_online_node`.
3. Скопіювати `windows/coursework.local.example.json` у
   `windows/coursework.local.json` і заповнити шляхи свого комп'ютера.
4. У Windows двічі клацнути `windows/START_COURSEWORK.cmd`. Панель відкриється
   за адресою `http://127.0.0.1:8080/`.
5. Вибрати сценарій і запустити симуляцію. Кнопки зупинки та закриття є в
   панелі. Для порівняння вибрати CSV-журнал телеметрії ДЗ11, підтвердити відповідність
   початкових даних і натиснути `ПОРІВНЯТИ З AIRSIM`.

`ВІДТВОРИТИ` показує файл лише у вебпанелі й **не запускає фізику AirSim**.
Порівняння теж не керує польотом: воно зіставляє два вже наявні записи шляху.
Файл користувача читається браузером локально й не надсилається серверу.
Як записати журнал ДЗ11: [docs/HW11_TELEMETRY.md](docs/HW11_TELEMETRY.md).

## Архітектура й перевірка

AirSim виконує фізичну симуляцію; `airsim_online_node` працює як C++ клієнт
RPC, отримує стан і публікує телеметрію ROS. Локальний сервер отримує стислий
стан через UDP, віддає панелі HTTP API та зберігає результати запусків у CSV.
Окремий `guidance_node` із `guidance_checker` — ROS-демонстрація із заглушкою;
її не слід плутати з повним AirSim-запуском.

Повні межі компонентів і API: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
Команди перевірки й чесний статус випробувань: [docs/VERIFICATION.md](docs/VERIFICATION.md).

## Відомі обмеження

- Готова сцена `WindowsNoEditor` запускається, але без вихідного Unreal-проєкту
  не редагується як повноцінна сцена в Unreal Editor.
- Новий комп'ютер потребує окремого встановлення ROS 2, C++ бібліотек AirSim
  та Windows-сцени. Поточний `.devcontainer` базового репозиторію не встановлює
  ROS/AirSim автоматично.
- Геометричне порівняння траєкторій не синхронізує час і не доводить, що
  точки пройдено в тому самому порядку.
- Порт 8080 доступний лише на `127.0.0.1`; панель не призначена для
  публічного серверного розгортання.

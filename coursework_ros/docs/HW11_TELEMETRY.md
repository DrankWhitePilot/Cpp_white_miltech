# Запис телеметрії ДЗ11 і порівняння з AirSim

Журнал містить отримані програмою ДЗ11 координати, час, висоту, швидкість
та інші поля телеметрії. Він не містить цілей, команд, параметрів скиду
або результатів ураження.

## Як отримати файл

1. Зібрати оновлений ДЗ11 у контейнері з кореня репозиторію:

   ```bash
   cmake -S . -B build/hw11_logging
   cmake --build build/hw11_logging --target mission_uart_drop -j2
   ```

2. У вже налаштованому запуску ДЗ11 із симулятором викладача використати
   оновлений виконуваний файл `build/hw11_logging/homework_11/mission_uart_drop`
   і додати до його наявних аргументів:

   ```text
   --telemetry-log /tmp/hw11_telemetry.csv
   ```

   Шляхи UART та налаштування симулятора залишаються з твого робочого запуску.
   Ім'я файла має бути новим: запис не перезаписує існуючий журнал. Каталог
   повинен існувати. Без цього параметра журналювання вимкнено.

3. Після отримання телеметрії скопіювати CSV з контейнера до Windows і вибрати
   його у полі **Телеметрія ДЗ11 (.csv)** у панелі. Наявність самого заголовка
   без щонайменше двох записів означає, що достатню телеметрію ще не отримано.
4. Для записаного запуску AirSim підтвердити однакові початкові умови,
   одиниці/початок координат і ділянку польоту; натиснути **ПОРІВНЯТИ З AIRSIM**.

Записувач дописує і скидає на диск кожен прийнятий коректний запис. Некінцеві
числа пропускаються з попередженням. Помилка запису також дає попередження;
такий журнал може бути неповним. Файловий ввід-вивід додає витрати часу до
обробки пакета; вимірювання цих витрат на симуляторі ще не виконано.

## Формат v1

Перші два рядки:

```text
# hw11-telemetry-v1
t_ms,x,y,z,vx,vy,speed,dir,state
```

Далі — один запис на пакет: час у мілісекундах, координати та висота в
метрах, компоненти швидкості й швидкість у м/с, напрям у радіанах, числовий
стан. Поля передаються без зміни системи координат протоколу ДЗ11.
Маркер формату позначає структуру файла, а не є доказом його походження.

Панель приймає 2–5000 записів одного польоту, не більше 5 МБ. Час має суворо
зростати; дублі, скидання лічильника, пошкоджені рядки й `NaN` відхиляються.
`simulation.json` ДЗ10 відхиляється цим режимом; він доступний окремо для
відтворення.

## Що показує порівняння

Два шляхи в площині XY, кількість точок, довжину й тривалість записів,
середню/95-й перцентиль/максимальну відстань точок AirSim до найближчих
сегментів записаного шляху ДЗ11. Висота, швидкість та інші поля зберігаються
у CSV, але поки не входять до цих геометричних метрик. Час не синхронізується.
Режим не встановлює причину розбіжності і не оцінює точність ураження.

Повноцінне порівняння потребує справжнього журналу від симулятора ДЗ11 та
запису відповідного запуску AirSim. Синтетичні файли використовуються лише
для перевірки читання формату.
